Project Overview

This project predicts NBA playoff series winners using regular season team quality, efficiency, and playoff-history features. It compares logistic regression, random forest, and XGBoost, then uses SHAP to explain the best model.

Model Comparison

Model Accuracy ROC-AUC
XGBoost 53.3% 0.683
Random Forest 56.7% 0.674
Logistic Regression 53.3% 0.647

What It Demonstrates

Series-level modeling

Reduces single-game noise by predicting best-of-seven playoff matchups.

Temporal validation

Uses recent playoff seasons as holdout data instead of random leakage-prone splits.

Explainability

Uses SHAP to communicate drivers such as offensive rating differential and opponent quality.
