# Eagles ML Predictor: Project Guide

## Purpose

This project predicts the result of every Philadelphia Eagles game in the 2026 NFL season.

The main output is not just a win/loss pick. Each game gets a win probability, a projected result,
and a confidence band. That matters because a 50.5% projected win and a 72.2% projected win are
very different kinds of predictions.

Current generated output:

```text
Projected record: 9-8
Prediction file: outputs/eagles_2026_predictions.csv
```

## What Exists Right Now

The project currently has three prediction layers:

1. A working preseason baseline that can already predict all 17 Eagles games.
2. A machine-learning training path that can train on historical NFL data after the optional
   nflverse dependency is installed.
3. A portfolio evaluation/reporting path that compares Elo, logistic regression, and histogram
   gradient boosting with season-forward validation.

The preseason baseline is useful because the 2026 season has not started yet. There are no 2026
Eagles game results, current-season EPA trends, or closing betting lines to learn from. The model
therefore starts with a transparent prior based on last season's records, home field, travel, and
special schedule conditions.

## Key Files

### `README.md`

The quick-start file. It explains how to run the project, where the output goes, and how to train
with historical NFL data.

### `PROJECT_GUIDE.md`

This document. It is meant to be the readable overview of the project and its moving parts.

### `docs/research.md`

The research summary. It explains why the project uses probabilities, why the first ML model is
logistic regression, which variables matter most, and how model quality should be measured.

### `data/processed/eagles_2026_schedule.csv`

The 2026 Eagles schedule used by the prediction script. It includes week, date, opponent, site,
venue, network, and notes such as London, Thanksgiving, and Thursday night.

### `data/processed/team_priors_2026.csv`

The preseason team-strength input. It stores each Eagles opponent's prior-season record. The
baseline converts those records into conservative Elo-style ratings.

### `outputs/eagles_2026_predictions.csv`

The generated prediction table. This is the file to open if you want the current game-by-game
forecast.

### `MODEL_REPORT.md`

The model report generated by the evaluation workflow. It summarizes the dataset, feature names,
validation method, model comparison, selected model, and limitations.

## Source Code Components

### `src/eagles_ml/cli.py`

The command-line entry point.

Important commands:

```bash
eagles-ml predict
```

Writes the 2026 Eagles predictions.

```bash
eagles-ml build-dataset --start 1999 --end 2025
```

Fetches historical NFL schedules and builds the processed leak-free feature table.

```bash
eagles-ml evaluate --dataset data/processed/historical_games.csv
```

Runs the season-forward model comparison and writes portfolio artifacts.

### `src/eagles_ml/elo.py`

Contains the preseason baseline math.

It does three things:

- Converts an Elo rating difference into a win probability.
- Converts a team's prior record into a conservative preseason Elo rating.
- Applies home-field, away-field, neutral-site, and situational adjustments.

This is the part that makes the project useful before the 2026 season starts.

### `src/eagles_ml/projections.py`

Turns the Eagles schedule and team priors into the final prediction table.

For each game, it:

- Looks up the Eagles and opponent ratings.
- Applies home/away/neutral-site context.
- Applies small schedule adjustments for London, Thanksgiving, Thursday night, and TBD timing.
- Produces a win probability.
- Converts the probability into a projected win/loss result.
- Assigns a confidence band.

### `src/eagles_ml/features.py`

Builds leak-free historical game features from nflverse-style schedule data.

"Leak-free" means the model only sees information that would have been known before the game.
That is important because using postgame information would make historical test scores look better
than real future predictions.

Current feature examples:

- Pregame Elo difference.
- Elo-implied home win probability.
- Recent point-margin difference.
- Recent win-rate difference.
- Rest-day difference.
- Spread line, when available.
- Weather fields, when available.

### `src/eagles_ml/model.py`

Contains the trainable machine-learning model.

The first model is an L2-regularized logistic model. It is a practical starting point because NFL
game data is relatively small, noisy, and easy to overfit. Logistic models are also easy to
interpret and can produce well-calibrated probabilities.

The module also includes scoring helpers:

- Brier score.
- Log loss.

### `src/eagles_ml/evaluation.py`

Runs season-forward validation across Elo, logistic regression, and histogram gradient boosting.
It writes model metrics, validation predictions, and calibration buckets.

### `src/eagles_ml/reporting.py`

Creates model-comparison charts, calibration charts, and the generated `MODEL_REPORT.md`.

### `app/streamlit_app.py`

Local Streamlit dashboard for reviewers. It shows the Eagles forecast, model metrics, calibration
artifacts, feature explanation, and caveats.

### `src/eagles_ml/data_sources.py`

Handles optional historical data loading through `nfl-data-py`.

This is separated from the rest of the code so the baseline project can run even when the optional
nflverse package is not installed.

## How To Run It

From the project directory:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
eagles-ml predict --output outputs/eagles_2026_predictions.csv
```

Portfolio command:

```bash
eagles-ml predict-2026 --model best --output outputs/eagles_2026_predictions.csv
```

To print the current projection table:

```bash
python -c "from eagles_ml.projections import project_eagles_games; p=project_eagles_games(); print(p[['week','date','opponent','site','eagles_win_probability','projected_result','confidence_band']].to_string(index=False))"
```

## How To Upgrade The Model

The next important upgrade is to install the optional nflverse dependency and train on historical
NFL schedules:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[nflverse,dev]'
eagles-ml build-dataset --start 1999 --end 2025
eagles-ml evaluate --dataset data/processed/historical_games.csv
```

Portfolio workflow:

```bash
eagles-ml build-dataset --start 1999 --end 2025
eagles-ml evaluate --dataset data/processed/historical_games.csv
eagles-ml predict-2026 --model best
streamlit run app/streamlit_app.py
```

After that, the best next variables to add are:

- Closing spread and game total.
- Rolling offensive and defensive EPA.
- Quarterback starter status.
- Injury reports.
- Rest and travel distance.
- Weather and wind.
- Divisional game indicator.

## How To Judge Whether The Model Is Good

Do not judge the model only by win/loss accuracy. NFL games are probabilistic, and the model should
be rewarded for knowing when it is uncertain.

Use these metrics:

- Brier score: measures probability error.
- Log loss: punishes overconfident wrong predictions.
- Calibration: checks whether games predicted at 60% actually win about 60% of the time.
- Accuracy: useful, but secondary.

Use season-forward validation. For example, train on 1999-2022, test on 2023; then train on
1999-2023, test on 2024. Random train/test splits are not appropriate because they leak future
season context into the training process.

## Important Caveats

This is a preseason model. It should be refreshed as new information becomes available.

The current output does not yet include:

- 2026 injuries.
- Actual 2026 roster changes.
- Market lines for each game.
- In-season Eagles performance.
- Opponent in-season performance.
- Weather forecasts.

Because of that, the current predictions are best understood as a structured preseason forecast,
not a final betting model.
